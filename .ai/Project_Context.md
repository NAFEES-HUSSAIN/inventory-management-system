# Project Context

## Project Name

Inventory Management System

## Business Type

Wholesale and Retail Business

## Goal

Build a production-ready inventory management system using Laravel.

The system must be scalable, maintainable, secure and suitable for real business operations.

---

## Technology Stack

Backend:
- Laravel 13
- PHP 8.4+

Frontend:
- Livewire 4
- Tailwind CSS 4

Database:
- MySQL 8+

Authentication:
- Laravel Breeze

Authorization:
- Spatie Laravel Permission

Audit Logs:
- Spatie Activity Log

Version Control:
- Git
- GitHub

Deployment:
- Linux VPS
- Nginx
- PHP-FPM
- MySQL

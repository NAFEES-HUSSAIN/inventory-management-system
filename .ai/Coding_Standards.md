Follow PSR-12.

Use strict typing.

Good:

## Methods

Single Responsibility Principle.

One method = One responsibility.

---

## Comments

Write meaningful code.

---

## Code Quality

No duplicate code.

No dead code.

No unused imports.

Always refactor when needed.

# Project Scope

Version: 1.0

Status: Approved

---

# Project Scope

This project covers the complete inventory management workflow for wholesale and retail businesses.

---

# In Scope

Authentication

- Login
- Profile
- Password Management

User Management

- Users
- Roles
- Permissions

Inventory

- Categories
- Products

Business Partners

- Suppliers
- Customers

Transactions

- Purchases
- Sales
- Customer Payments

Reporting

- Sales Reports
- Purchase Reports
- Stock Reports

Administration

- Dashboard
- Audit Logs
- Company Settings

---

# Out of Scope

The following features are excluded from Version 1.0

- Multi Branch
- Mobile Application
- Barcode Printing
- QR Payments
- SMS Integration
- Email Marketing
- Accounting Module
- AI Forecasting

These features may be implemented in future releases.

---

# Assumptions

- Users have internet access.
- Business operates from a single branch.
- MySQL is the primary database.
- Laravel is the backend framework.

---

# Constraints

- Development follows Laravel standards.
- Security rules must always be followed.
- Role-based authorization is mandatory.
- Every module must support responsive UI.

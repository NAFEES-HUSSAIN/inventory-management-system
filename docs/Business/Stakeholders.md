# Project Stakeholders

---

## Client

Owns the business.

Responsibilities

- Approves requirements
- Reviews progress
- Accepts final product

---

## Project Manager

Responsibilities

- Project planning
- Timeline management
- Resource allocation
- Risk management

---

## Software Architect

Responsibilities

- System architecture
- Technology selection
- Database design
- Security planning

---

## Software Developer

Responsibilities

- Feature development
- Bug fixing
- Unit testing
- Documentation

---

## UI/UX Designer

Responsibilities

- Wireframes
- High Fidelity Design
- Design System
- User Experience

---

## Quality Assurance (QA)

Responsibilities

- Testing
- Bug reporting
- Validation
- User acceptance support

---

## System Administrator

Responsibilities

- Deployment
- Server maintenance
- Database backup
- Monitoring

---

## End Users

Admin

- Full system access

Employee

- Limited access based on permissions

---

# Communication

All changes must be documented.

Requirements must be approved before development begins.

Major architectural changes require project review.
